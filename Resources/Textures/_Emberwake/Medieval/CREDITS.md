# Medieval armory

Aftermath assembled the medieval weapons for Reclamation Project using RogueTown art supplied by Chermaity. Chermaity drew the medieval clothing and armor for Misfits. The original credits for individual assets, including the bow carrying poses, are in each sprite pack’s `meta.json`. [Reclamation weapons](https://github.com/BluCottonCandy/Reclamation-Project/pull/212) · [Original armor](https://github.com/BluCottonCandy/Reclamation-Project/tree/51c3dc032ba933c2495ae5f042b33b2a66cd4e4e/Resources/Textures/_Misfits/Clothing/Medieval)

The sprites retain [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Emberwake adapted the carrying poses, hand and back layers, and missing directional frames. The project owner confirmed creator permission to use these packs in Emberwake.

The adapted gameplay code and item definitions come from [Reclamation Project](https://github.com/BluCottonCandy/Reclamation-Project/tree/51c3dc032ba933c2495ae5f042b33b2a66cd4e4e) under its [AGPLv3 code license](https://github.com/BluCottonCandy/Reclamation-Project/blob/51c3dc032ba933c2495ae5f042b33b2a66cd4e4e/LEGAL.md).
